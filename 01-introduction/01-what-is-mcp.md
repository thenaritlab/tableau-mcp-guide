# 1.1 MCP คืออะไร ทำไมถึงสำคัญ

> ระดับ: 🟢 Basic | เวลาอ่าน: ~8 นาที

## ปัญหาก่อนจะมี MCP

AI อย่าง Claude ฉลาดมากในการวิเคราะห์และตอบคำถาม แต่มีข้อจำกัดใหญ่: **มันมองไม่เห็นข้อมูลของคุณ** — ไม่รู้ว่าใน Tableau ของบริษัทคุณมี dashboard อะไร ยอดขายเดือนนี้เท่าไหร่ หรือ data source ชื่ออะไรบ้าง

ก่อนหน้านี้ถ้าอยากให้ AI ช่วยวิเคราะห์ข้อมูล เราต้อง:

1. Export ข้อมูลจาก Tableau เป็น CSV/Excel
2. Copy-paste หรืออัปโหลดให้ AI
3. ถามคำถาม
4. ข้อมูลเปลี่ยน → กลับไปทำข้อ 1 ใหม่ 🔁

นอกจากเสียเวลาแล้ว ยังเสี่ยงเรื่องข้อมูลหลุด (copy ไปวางที่ไหนบ้างไม่มีใครตาม) และ AI ไม่เคยเห็นข้อมูล "สด" จริง ๆ

อีกทางคือให้นักพัฒนาเขียน integration เอง — แต่ทุกบริษัทต้องเขียน connector ของตัวเองกับทุกระบบ (Tableau, Salesforce, ฐานข้อมูล, ...) คูณกับ AI ทุกเจ้า กลายเป็นงานซ้ำซ้อนมหาศาลที่เรียกกันว่า **ปัญหา M×N** (M ระบบ × N AI = ต้องเขียน M×N connectors)

## MCP คือคำตอบ

**Model Context Protocol (MCP)** คือมาตรฐานกลาง (open standard) ที่ Anthropic เปิดตัวปลายปี 2024 สำหรับเชื่อม AI เข้ากับระบบภายนอก — เปรียบง่าย ๆ คือ **"USB-C ของโลก AI"**

- สมัยก่อน: มือถือแต่ละยี่ห้อใช้สายชาร์จคนละแบบ
- USB-C มา: ทุกอุปกรณ์ใช้หัวเดียวกัน
- MCP ก็เช่นกัน: ระบบไหนทำ **MCP Server** ไว้ครั้งเดียว → AI ทุกตัวที่รองรับ MCP (Claude, ChatGPT, Cursor, ฯลฯ) ต่อเข้าใช้ได้ทันที

จากปัญหา M×N เหลือแค่ M+N: แต่ละระบบทำ server 1 ตัว แต่ละ AI ทำ client 1 ตัว จบ

## องค์ประกอบของ MCP

```
[MCP Host/Client]  ←── MCP Protocol ──→  [MCP Server]  ──→  [ระบบจริง]
เช่น Claude Desktop                       เช่น Tableau MCP      เช่น Tableau Cloud
```

| ส่วน | คืออะไร | ตัวอย่าง |
|---|---|---|
| **MCP Host / Client** | โปรแกรม AI ที่ผู้ใช้คุยด้วย | Claude Desktop, Claude.ai, Cursor |
| **MCP Server** | ตัวกลางที่ "แปล" ความสามารถของระบบให้ AI เข้าใจ | tableau-mcp, GitHub MCP, Slack MCP |
| **ระบบจริง** | แหล่งข้อมูล/บริการปลายทาง | Tableau, GitHub, ฐานข้อมูล |

### สิ่งที่ MCP Server เสนอให้ AI มี 3 ประเภท

1. **Tools** — "การกระทำ" ที่ AI เรียกใช้ได้ เช่น `query-datasource` (query ข้อมูล), `search-content` (ค้นหา workbook) — นี่คือส่วนที่ใช้บ่อยสุด
2. **Resources** — ข้อมูล/เอกสารที่ AI อ่านได้
3. **Prompts** — template คำสั่งสำเร็จรูป

## แล้ว AI ตัดสินใจใช้ tool อย่างไร?

จุดที่หลายคนเข้าใจผิด: เราไม่ได้สั่งว่า "จงเรียก tool X" — เราถามคำถามปกติ แล้ว **AI ตัดสินใจเองว่าต้องใช้ tool ไหน ลำดับอย่างไร**

ตัวอย่าง ถามว่า *"ยอดขาย 5 อันดับแรกรายจังหวัดปีนี้เท่าไหร่"*:

```
1. Claude อ่านคำถาม → รู้ว่าต้องการข้อมูลจาก Tableau
2. เรียก list-datasources → เห็นว่ามี data source "Sales_2026"
3. เรียก list-fields → รู้ว่ามี field "จังหวัด" และ "ยอดขาย"
4. เรียก query-datasource → ได้ตัวเลขจริงกลับมา
5. เรียบเรียงเป็นคำตอบภาษาคน พร้อมข้อสังเกต
```

ทั้งหมดเกิดในไม่กี่วินาที และทุก tool call จะแสดงให้เราเห็น (และอนุมัติ) ได้

## ทำไม MCP ถึงจุดติดเร็วมาก

- เป็น open standard — ไม่ผูกกับ AI เจ้าใดเจ้าหนึ่ง ปัจจุบันผู้เล่นรายใหญ่รองรับกันเกือบหมด
- Ecosystem โตเร็ว — MCP server มีเป็นหลักหมื่นตัวแล้ว ครอบคลุมตั้งแต่ฐานข้อมูล, SaaS, ไปจนถึงเครื่องมือภายในองค์กร
- ฝั่ง enterprise software (รวมถึง Tableau/Salesforce) ทำ official server เอง — เป็นสัญญาณว่านี่คือมาตรฐานระยะยาว ไม่ใช่ของเล่นชั่วคราว

## สรุปสั้น ๆ

> MCP = มาตรฐานกลางที่ทำให้ AI "ยื่นมือ" ออกไปใช้งานระบบอื่นได้อย่างปลอดภัยและเป็นระเบียบ และ **Tableau MCP** คือ server ทางการที่ทำให้มือของ AI เอื้อมถึงข้อมูลใน Tableau ของคุณ — ซึ่งเป็นพระเอกของคู่มือเล่มนี้
