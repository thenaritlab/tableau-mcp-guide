# 1.3 Use Cases: ใครควรใช้ / ใช้ทำอะไรได้บ้าง

> ระดับ: 🟢 Basic | เวลาอ่าน: ~8 นาที

## แบ่งตามบทบาทผู้ใช้

### 👔 ผู้บริหาร / Business User

**Pain เดิม:** อยากรู้ตัวเลขต้องเปิด dashboard เอง หา filter เอง หรือรอทีม data ตอบ

**กับ Tableau MCP:**

- ถามตัวเลขเป็นภาษาพูดได้เลย — *"ยอดขายสะสม Q3 ถึงเป้าหรือยัง ขาดเท่าไหร่"*
- ให้ AI สรุป Pulse metrics ประจำสัปดาห์ — *"สรุป metric ที่ฉัน follow อยู่ อันไหนน่ากังวลบ้าง"*
- ถามคำถามต่อเนื่องเจาะลึกได้เหมือนคุยกับ analyst — "แล้วถ้าตัดลูกค้ารายใหญ่ 1 รายออกล่ะ?"

### 📊 Data Analyst

**Pain เดิม:** งาน ad-hoc query ถล่ม, เขียน doc ให้ dashboard ไม่มีเวลา

**กับ Tableau MCP:**

- ทำ **exploratory analysis เร็วขึ้นมาก** — ไล่ถามข้อมูลหลายมุมโดยไม่ต้องลาก viz ทีละอัน
- **สร้าง documentation อัตโนมัติ** — ให้ AI ไล่อ่าน metadata แล้วเขียน data dictionary ให้ (ดูบท 4.4)
- ตรวจสอบคุณภาพข้อมูล — *"field ไหนใน data source นี้มีค่า null เยอะผิดปกติ"*
- เป็น "ผู้ช่วยตอบคำถาม" ให้ business user ถามเองก่อน จะได้เหลือแต่คำถามยาก ๆ มาถึงเรา

### 🛠️ Tableau Admin / BI Team

- ค้นหา content ข้าม site เร็ว ๆ — *"workbook ไหนบ้างที่ใช้ data source ตัวเก่าที่กำลังจะปลด"*
- ดู usage — *"workbook ไหนถูกเปิดดูเยอะสุดใน 90 วัน"* ประกอบการตัดสินใจ cleanup
- ตอบคำถาม user แทนการเปิด ticket ง่าย ๆ

### 👨‍💻 Developer

- สร้าง **"Chat with your data" app** ให้องค์กร — web app ที่พนักงานถามข้อมูลผ่านแชท เบื้องหลังคือ Claude API + Tableau MCP (ดู Part 5.3)
- ฝัง AI insights ใน workflow อื่น — เช่น สรุปตัวเลขอัตโนมัติส่งเข้า LINE/Slack ทุกเช้า
- ต่อยอดเป็น agentic workflow ที่ตัดสินใจหลายขั้น (ดู Part 5.7)

## ตัวอย่างสถานการณ์จริง

### สถานการณ์ 1: ประชุมผู้บริหารเช้าวันจันทร์

แทนที่จะเตรียม slide ตัวเลขล่วงหน้าทั้งหมด เปิด Claude ที่ต่อ MCP ไว้กลางห้องประชุม — ผู้บริหารถามอะไร query สดตรงนั้น ตัวเลขล่าสุดเสมอ คำถาม follow-up ("แยกตามสาขาให้ดูหน่อย") ตอบได้ทันทีไม่ต้อง "ขอกลับไปดูก่อนครับ"

### สถานการณ์ 2: Onboard พนักงานใหม่เข้าทีม data

พนักงานใหม่ไม่รู้ว่าองค์กรมีข้อมูลอะไรบ้าง — ให้ถาม AI ได้เลย: *"มี data source อะไรเกี่ยวกับลูกค้าบ้าง แต่ละตัวต่างกันยังไง"* AI ไล่อ่าน metadata และ description มาสรุปให้ ลดเวลา onboarding จากสัปดาห์เหลือวันเดียว

### สถานการณ์ 3: รายงานประจำสัปดาห์อัตโนมัติ

Developer เขียน script เรียก Claude API + Tableau MCP ทุกเย็นวันศุกร์: query ยอดสัปดาห์ → เทียบสัปดาห์ก่อน → ให้ AI เขียนสรุป 1 หน้า → ส่งอีเมลทีมขาย ทั้ง pipeline ไม่มีคนแตะเลย

## สิ่งที่ Tableau MCP (ยัง) ไม่เหมาะ

เพื่อความคาดหวังที่ถูกต้อง — อย่าเพิ่งเอาไปใช้กับงานเหล่านี้:

| งาน | เพราะอะไร | ใช้อะไรแทน |
|---|---|---|
| สร้าง/แก้ workbook, ออกแบบ viz | ไม่ใช่ขอบเขตของ MCP ปัจจุบัน | Tableau Desktop / Web Authoring |
| Query ตารางดิบใน database ตรง ๆ | MCP คุยผ่าน published data source | Database MCP (Postgres MCP ฯลฯ) |
| Dashboard แบบ realtime refresh ทุกวินาที | MCP เหมาะกับ ad-hoc ถาม-ตอบ | Tableau dashboard ปกติ |
| ตัดสินใจสำคัญโดยไม่ตรวจทาน | AI ตีความคำถามผิดได้ query ผิด field ได้ | ใช้ AI เป็น first draft แล้วคนตรวจ |

> ⚠️ **กฎทองของการใช้ AI กับข้อมูล:** ตัวเลขที่ AI ตอบมาจาก query จริงก็จริง แต่ "การตีความคำถาม" อาจคลาดเคลื่อน เช่น "ยอดขาย" คุณหมายถึง gross แต่ AI หยิบ net — ตัวเลขสำคัญให้ขอดู query ที่ใช้ประกอบเสมอ (เทคนิคอยู่ในบท 4.1)
