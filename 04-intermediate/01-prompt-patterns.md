# 4.1 Prompt Patterns: เทคนิคเขียน prompt ให้ Claude query แม่น

> ระดับ: 🟡 Intermediate

จาก Part 3 คุณ query พื้นฐานได้แล้ว — บทนี้คือ pattern ที่ยกระดับความแม่นและความเร็วในงานจริง

## Pattern 1: Context Priming (บอกบริบทก่อนเริ่ม)

เปิดบทสนทนาด้วยการ "ตั้งกติกา" ครั้งเดียว ใช้ได้ทั้งแชท:

```
บริบทก่อนเริ่ม:
- ใช้ data source "Sales_2026" เป็นหลัก
- "ยอดขาย" = field [Net Sales] เสมอ (ไม่ใช่ Gross)
- ปีงบประมาณเราเริ่ม 1 ต.ค.
- ตอบเป็นภาษาไทย ตัวเลขใส่ comma
พร้อมแล้วบอก แล้วฉันจะเริ่มถาม
```

แก้ปัญหาคลาสสิก: AI หยิบ field ผิดตัว, ตีความ "ปีนี้" ไม่ตรงกับธุรกิจ

## Pattern 2: Explore → Confirm → Query (สำหรับ data source ใหม่)

อย่าให้ AI เดา field เอง กับข้อมูลที่มันไม่เคยเห็น:

```
ขั้น 1: "ดู fields ของ data source นี้ก่อน แล้วบอกว่า field ไหน
        น่าจะหมายถึง ยอดขาย, สาขา, และวันที่ทำรายการ"
ขั้น 2: [ตรวจคำตอบ ยืนยันหรือแก้]
ขั้น 3: "โอเค ใช้ตามนั้น query ยอดขายรายสาขา 3 เดือนล่าสุด"
```

ช้ากว่า 1 นาที แต่ตัดโอกาส query ผิดทั้งบทสนทนา

## Pattern 3: Output Template (กำหนดรูปแบบผลลัพธ์)

```
ทุกครั้งที่ตอบตัวเลข ใช้โครงนี้:
📌 คำตอบสั้น (1 บรรทัด)
📊 ตาราง/ตัวเลขละเอียด
🔍 Query ที่ใช้ (field + filter)
💡 ข้อสังเกต 1-2 ข้อ
```

ส่วน 🔍 คือ built-in audit — เห็น query ทุกครั้ง ผิดจะรู้ทันที

## Pattern 4: Chain-of-Analysis (งานวิเคราะห์หลายขั้น)

งานซับซ้อนให้แตกขั้นตอนให้ AI เดินตาม แทนการถามก้อนเดียว:

```
วิเคราะห์สาเหตุยอดขายตกเดือนนี้ ทำตามลำดับ:
1. ยืนยันก่อนว่าตกจริงไหม เทียบ MoM และ YoY
2. แตกตามมิติ: ภาค, ช่องทาง, หมวดสินค้า — หามิติที่ตกแรงสุด
3. เจาะมิตินั้นลงลึกอีกชั้น
4. เช็คว่าเป็น volume ตก หรือราคาเฉลี่ยตก
5. สรุปสมมติฐานสาเหตุ 3 ข้อ เรียงตามความน่าจะเป็น
ทำทีละขั้น แสดงผลแต่ละขั้นก่อนไปต่อ
```

## Pattern 5: Negative Instructions (บอกสิ่งที่ห้ามทำ)

| ปัญหาที่เจอ | คำสั่งแก้ |
|---|---|
| AI ดึงข้อมูลเยอะเกินจนช้า | "ทุก query ใส่ limit ไม่เกิน 100 แถว ถ้าต้องการมากกว่านั้นให้ถามก่อน" |
| ชอบสรุปเกินข้อมูล | "ห้ามสรุปสาเหตุถ้าข้อมูลไม่รองรับ ให้บอกว่าต้อง query อะไรเพิ่ม" |
| ปัดเศษเอง | "แสดงทศนิยม 2 ตำแหน่งเสมอ ห้ามปัดเป็นจำนวนเต็ม" |

## Pattern 6: Saved Prompt Library

Prompt ที่ใช้ซ้ำทุกสัปดาห์ ให้เก็บเป็นไฟล์ (ดู [examples/sample-prompts.md](../examples/sample-prompts.md)) หรือใส่ใน Claude Projects (บท 4.5) — ทีมใช้ prompt เดียวกัน = ได้รายงานรูปแบบเดียวกัน

## Anti-patterns (สิ่งที่ทำแล้วผลแย่)

1. **ถามหลายเรื่องในประโยคเดียว** — "ยอดขาย กำไร และ inventory เทียบปีก่อนแยกตามภาคกับหมวด" → แตกเป็นหลายคำถาม
2. **ใช้ศัพท์ภายในที่ไม่มีในข้อมูล** — คุณเรียก "ยอด GT" แต่ field ชื่อ `Traditional Trade Sales` → ทำ glossary ใน context priming
3. **เปลี่ยนเรื่องในแชทเดิมไปเรื่อย ๆ** — context ปนกัน AI เริ่มหยิบ filter เก่ามาใช้มั่ว → เรื่องใหม่ = แชทใหม่
