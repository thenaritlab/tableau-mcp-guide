# 🎯 รวม Prompt สำเร็จรูป (Copy ไปใช้ได้เลย)

> แก้ชื่อ data source / field ในวงเล็บเหลี่ยมให้เป็นของคุณ — pattern เบื้องหลังอ่านได้ที่ [บท 4.1](../04-intermediate/01-prompt-patterns.md)

## 🏁 Context Priming (วางเป็นข้อความแรกของแชท)

```
บริบทก่อนเริ่ม:
- ใช้ data source "[Sales_2026]" เป็นหลัก
- "ยอดขาย" = field [Net Sales] เสมอ
- ปีงบประมาณเริ่ม [1 ต.ค.]
- ตอบภาษาไทย ตัวเลขใส่ comma ทศนิยม 2 ตำแหน่ง
- ทุกคำตอบตัวเลข แนบ query ที่ใช้ (field + filter) ท้ายคำตอบ
- limit ทุก query ไม่เกิน 100 แถว
พร้อมแล้วตอบ "พร้อม" แล้วฉันจะเริ่มถาม
```

## 📊 รายงานประจำ

**Weekly Sales Report:**

```
ทำรายงานยอดขายสัปดาห์ล่าสุด (จันทร์-อาทิตย์ที่ผ่านมา):
1. ยอดรวม + เทียบสัปดาห์ก่อน (%)
2. Top 5 [สินค้า/สาขา] + Bottom 3
3. มิติไหนเปลี่ยนแปลงผิดปกติ (เบี่ยงเกิน 20% จากค่าเฉลี่ย 4 สัปดาห์)
4. สรุปผู้บริหาร 3 bullet
```

**Morning Briefing จาก Pulse:**

```
ดึง insight ของทุก Pulse metric ที่ฉัน follow แล้วสรุป:
🔴 ต้องดูด่วน / 🟢 ข่าวดี / 😐 ทรงตัว (บรรทัดเดียว)
แต่ละข้อใส่ตัวเลข + % ปิดท้าย "คำถามที่ควรถามต่อในที่ประชุม" 2 ข้อ
```

## 🔍 วิเคราะห์เจาะลึก

**Root Cause หายอดตก:**

```
วิเคราะห์สาเหตุ[ยอดขาย]ตก[เดือนนี้] ทำทีละขั้น แสดงผลทุกขั้น:
1. ยืนยันว่าตกจริง (MoM + YoY)
2. แตกมิติ [ภาค/ช่องทาง/หมวด] หามิติที่ตกแรงสุด
3. เจาะมิตินั้นลงอีกชั้น
4. Volume ตก หรือราคาเฉลี่ยตก?
5. สมมติฐานสาเหตุ 3 ข้อ เรียงตามความน่าจะเป็น
```

**หา Anomaly:**

```
ใน 12 เดือนล่าสุด เดือนไหน[ยอดขาย]เบี่ยงจากค่าเฉลี่ยเกิน 20%
ทั้งบวกและลบ พร้อมเดาสาเหตุจากมิติอื่นที่มีในข้อมูล
```

**Concentration Risk:**

```
ลูกค้า Top 10 คิดเป็นกี่ % ของยอดรวม และถ้าตัด Top 10 ออก
ยอดที่เหลือโตหรือหดเทียบปีก่อน — เราพึ่งลูกค้าใหญ่เกินไปไหม
```

## 🔄 เทียบ / กระทบยอด

**Actual vs Target (คนละ data source):**

```
1. จาก "[Sales_Actual]" ดึงยอดจริงรายเดือนปีนี้
2. จาก "[Sales_Target]" ดึงเป้ารายเดือนปีนี้
3. ตาราง: เดือน | จริง | เป้า | ผลต่าง | %achieve — ต่ำกว่า 90% flag 🔴
```

**Reconciliation:**

```
ยอดรวมเดือน[ก.ค.]จาก "[DS_A]" กับ "[DS_B]" ตรงกันไหม
ถ้าไม่ตรง ต่างเท่าไหร่ และแตกรายวันดูว่าผลต่างกระจุกวันไหน
```

## 📝 Documentation

**Data Dictionary:**

```
สร้าง data dictionary ของ "[DS]" เป็นตาราง markdown:
| Field | ชนิด | คำอธิบาย | ตัวอย่างค่า 3 ค่า | หมายเหตุ |
- คำอธิบายจาก metadata ถ้ามี ไม่มีให้เดาจากชื่อแล้วติด [ต้องตรวจ]
- หมายเหตุ: flag field ที่ null เกิน 10%
- ท้ายเอกสารใส่วันที่จัดทำ
```

**คู่มือ Dashboard สำหรับ User:**

```
ทำคู่มือผู้ใช้ workbook "[ชื่อ]": ดู views ทั้งหมด + ดึงภาพ
ต่อ view อธิบาย: ตอบคำถามธุรกิจอะไร / อ่าน chart อย่างไร /
filter และข้อควรระวัง — ปิดท้าย FAQ 5 ข้อ
เขียนให้คนไม่เคยใช้ Tableau อ่านรู้เรื่อง
```

## 🧹 งาน Admin

**หา candidate สำหรับ archive:**

```
ทำ inventory project "[ชื่อ]": workbook | owner | แก้ล่าสุด | views 90 วัน
เรียง views น้อย→มาก — ไม่มีคนดู 90 วัน + ไม่แก้ 6 เดือน
ให้สถานะ "candidate for archive"
```

## ✅ ตรวจสอบคำตอบ (ใช้ตามหลังคำตอบไหนก็ได้)

```
ตัวเลขนี้ query มายังไง ใช้ field ไหน filter อะไร มีอะไรที่อาจ
ทำให้ตีความผิดจากที่ฉันตั้งใจถามไหม
```
