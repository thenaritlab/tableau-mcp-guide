# 3.1 บทสนทนาแรกกับข้อมูลของคุณ

> ระดับ: 🟢 Basic | ต้องติดตั้ง MCP เสร็จแล้ว (Part 2)

## เริ่มจากคำถาม "สำรวจ" ก่อนเสมอ

อย่าเพิ่งถามคำถามวิเคราะห์ยาก ๆ — ให้เริ่มจากการชวน AI สำรวจว่ามีอะไรให้เล่นบ้าง:

```
มี data source อะไรบ้างใน site ของฉัน
```

Claude จะเรียก tool (ครั้งแรกจะขออนุญาต — กด **Allow**) แล้วตอบรายชื่อกลับมา จากนั้นเจาะตัวที่สนใจ:

```
data source "Superstore" มี field อะไรบ้าง อธิบายแต่ละ field ให้ฟังหน่อย
```

ขั้นนี้สำคัญกว่าที่คิด — เมื่อ Claude ได้เห็นรายชื่อ field แล้ว คำถามต่อ ๆ ไปในบทสนทนาเดียวกันจะแม่นขึ้นมาก เพราะมันรู้แล้วว่าข้อมูลหน้าตาเป็นอย่างไร

## ไต่ระดับคำถาม

### ระดับ 1 — ข้อเท็จจริงตรง ๆ

```
ยอดขายรวมทั้งหมดใน Superstore เท่าไหร่
```

### ระดับ 2 — จัดกลุ่ม + จัดอันดับ

```
Top 5 จังหวัดที่ยอดขายสูงสุด พร้อมตัวเลข
```

### ระดับ 3 — เงื่อนไข + ช่วงเวลา

```
ยอดขายรายเดือนของปี 2026 เฉพาะหมวด Technology
เทียบกับช่วงเดียวกันของปีที่แล้ว เป็นเปอร์เซ็นต์
```

### ระดับ 4 — วิเคราะห์ + ขอความเห็น

```
กำไร (profit) ของเรามีจังหวัดไหนติดลบบ้าง
ลองวิเคราะห์ว่าน่าจะเกิดจากอะไร ดูจาก discount ประกอบด้วย
```

สังเกตว่าระดับ 4 คือจุดที่ MCP เหนือกว่า dashboard ปกติ — AI ไม่ได้แค่ดึงตัวเลข แต่ query หลายรอบ เชื่อมโยง แล้วตั้งสมมติฐานให้เราต่อยอด

## การสนทนาต่อเนื่อง (Follow-up) คือพลังที่แท้จริง

ใน 1 บทสนทนา Claude จำ context ทั้งหมด — ใช้ประโยชน์เต็มที่:

```
คุณ:    Top 5 สินค้าขายดีเดือนนี้
Claude: [ตอบ 5 รายการ]
คุณ:    ตัวที่ 1 น่ะ ยอดมาจากลูกค้ากลุ่มไหนเป็นหลัก
Claude: [query ต่อโดยรู้ว่า "ตัวที่ 1" คืออะไร]
คุณ:    งั้นลองดูย้อนหลัง 6 เดือนซิ ขายดีตลอดหรือเพิ่งมาพีค
```

> 💡 **เคล็ดลับ:** งานวิเคราะห์เรื่องเดียวกันให้อยู่ในบทสนทนาเดียวกันยาว ๆ / ขึ้นเรื่องใหม่ให้เปิดแชทใหม่ — context ที่สะสมจะได้ไม่ปนกัน

## เมื่อคำตอบดูแปลก ให้ทำแบบนี้

ตัวเลขไม่ตรงกับที่คาด? อย่าเพิ่งเชื่อหรือทิ้ง — ถามกลับ:

```
ตัวเลขนี้ query มายังไง ใช้ field ไหน filter อะไรบ้าง
```

Claude จะอธิบาย query ที่ใช้ ซึ่งมักเจอสาเหตุทันที เช่น ใช้ field `Sales` แทน `Net Sales`, ลืม filter ปี, หรือตีความ "เดือนนี้" เป็น calendar month ในขณะที่บริษัทคุณใช้ fiscal month

สั่งแก้ได้เลย:

```
ใช้ Net Sales แทน และเดือนนี้หมายถึง fiscal month ที่เริ่มวันที่ 25
```
